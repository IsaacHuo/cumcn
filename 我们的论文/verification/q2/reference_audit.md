# 问题二参考材料核查（不进入论文正文）

本模型从原题、附件一电价和附件二实际数据独立构建，示例只作对照。

- `C题/示例论文/论文(1).pdf` 为扫描图，文本提取为空不能判定文件损坏。已按图像检查问题二第12–18页。文中采用同星期近三周负载预测、近5日光伏均值、跨日SOC与实时平衡；报告费用约1440.85万元。
- `C题论文.pdf` 对应 `C题v2.0/05_代码/solve_c.py` 采用另一实现：第351–356行是7日滚动均值；第424–445行默认逐日独立6000 kWh循环，第443行调用确定性预测LP，并非文中所称情景期望优化。
- 后者第445行将当日完整 `L[d],P[d]` 交给 `execute_plan`，第239–246行一次性建立整天执行约束，使执行动作依赖未来实测。
- 后者第240–242行实际供需约束为 `charge-discharge-curtail+emergency-shed=load-pv-plan`，充电和放电的符号与其正常SOC递推相反。按导出结果复算，2025-02-02的日能流残差约为-8751.96 kWh，不能由非负弃光解释。因此，不能把该结果的低费用作为有效基准。

主方案严格分离历史构模与当前观测。情景内未来动作明确作为前瞻松弛，真实绩效来自因果滚动执行；电能流独立重建核验，不以求解器成功或SOC闭合替代母线守恒检查。
